# docs/ — пояснительные заметки проекта

Эти файлы — копия заметок проекта из Obsidian-хранилища автора. Источник истины живёт в
хранилище, здесь лежит снимок для GitHub: чтобы человек, открывший репозиторий, понял
идею, архитектуру и демо-сценарий, не читая код.

Заметки связаны внутренними ссылками вида `[[01 Архитектура]]`. На GitHub они не
работают: используйте имена файлов. Проще всего начать с `00 Обзор идеи.md`, затем
`01 Архитектура.md`.

## Список заметок

1. `00 Обзор идеи.md` — суть в одном абзаце, боль аудитории (NDA, 152-ФЗ, GDPR), отличие от облачных ИИ.
2. `01 Архитектура.md` — слои системы, схема потока данных, таблица шести инструментов агента.
3. `02 Модель и железо.md` — целевая машина, qwen2.5:3b и 1.5b, лицензии моделей, check_ram.py.
4. `03 Как запустить.md` — установка, запуск, проверка офлайна, переменные окружения.
5. `04 Демо-сценарий для акселератора.md` — сценарий на 3-5 минут, трюк с отключением сети, вопросы жюри.
6. `05 Топ-функции и отличия.md` — что входит в MVP и что сознательно не делаем.
7. `06 Демо и ограничения.md` — честные ограничения демо и как превращать их в аргумент.
8. `07 Монетизация и обновления.md` — разовая покупка, подписка, гибрид, риски, открытые вопросы.
9. `акселиратор.md` — индексная заметка со ссылками.

Техническую документацию для разработчиков и агентов см. в `AGENTS.md` в корне, а
контракт интерфейсов в `SPEC.md`.
