# Как запустить

Все команды выполняются из корня проекта `/home/hio/институт/акселетартор2026/`.

## Что нужно заранее

- Python 3.12 через `uv`.
- Установленный Ollama.

## Установка: `install.sh`

Скрипт идемпотентный, интернет нужен один раз. По шагам:

1. Проверяет ОЗУ через `scripts/check_ram.py`.
2. Создаёт окружение: `uv venv --python 3.12 .venv`.
3. Ставит зависимости: `uv pip install -e .`.
4. Проверяет наличие Ollama.
5. Качает модель: `ollama pull $VANYA_MODEL`.
6. Генерирует шаблон и тестовые сэмплы.

```bash
bash install.sh
```

Если модель качать не нужно (например, нет диска или качаем позже), есть флаг:

```bash
bash install.sh --skip-model
```

## Запуск: `run.sh`

Активирует venv, включает офлайн-режим (`VANYA_OFFLINE=1` по умолчанию), стартует сервер и печатает URL.

```bash
bash run.sh
```

Для отладки (только локально, сеть разрешена):

```bash
bash run.sh --no-offline
```

## Открыть приложение

После запуска открыть в браузере:

```
http://127.0.0.1:8765
```

Порт по умолчанию 8765, меняется через `VANYA_PORT`.

## Проверка офлайн-режима

Два способа убедиться, что приложение не ходит в интернет:

- **Физически**: выдернуть сетевой кабель или выключить Wi-Fi, затем прогнать детерминированный сценарий (заполнение договора). Всё продолжит работать.
- **Переменной**: запустить с явным `VANYA_OFFLINE=1` и смотреть, что единственное сетевое соединение — это Ollama на loopback.

Самый наглядный трюк для демо описан в [[04 Демо-сценарий для акселератора]].

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `VANYA_MODEL` | `qwen2.5:3b` | модель Ollama |
| `VANYA_OLLAMA_URL` | `http://127.0.0.1:11434` | адрес Ollama |
| `VANYA_WORKSPACE` | `<repo>/workspace` | папка с документами и отчётами |
| `VANYA_PORT` | `8765` | порт веб-интерфейса |
| `VANYA_OFFLINE` | `true` | строгий офлайн-режим, блокирует всё кроме loopback |

Ещё есть `max_ctx_chars` (по умолчанию 12000, сколько символов документов кладётся в промпт), но он задаётся в конфиге, а не через переменную окружения.
